# 데이터 플래닛

이 저장소는 기존 `data-planet`과 분리된 행성 로고 버전입니다. 메인의 양쪽 위 행성에는 교육청 이름을 제외한 원형 심벌만 반투명하게 배치합니다.

## 태블릿 지원

- 모든 차시의 메뉴와 버튼에 터치 영역을 확보하고, 실제 표시 높이에 맞춰 활동 프레임을 조정합니다.
- 밸런스게임은 세로 화면에서 선택지를 위아래로, 결과 비교를 2열로 표시합니다. 비교 결과와 이유 작성 화면은 스크롤할 수 있습니다.
- 브라우저가 요소 전체 화면을 지원하지 않으면 화면 내 확대 모드를 사용합니다.
- 데이터런은 짧은 가로 화면에서도 점프 버튼이 잘리지 않도록 게임 높이를 조절합니다.
- 브라우저의 768×1024, 1024×768 뷰포트에서 카드 분류, 테트리스 분류·해설·조작 영역, 지도 장소 선택·발견 카드 작성 창, 밸런스게임 선택·이유 작성·비교, 데이터런 터치 점프, 전체 화면 열기·닫기를 확인했습니다. 실제 iPad/Safari 및 Android 기기 테스트를 의미하지는 않습니다.
- 외부 도구인 초등이지통계와 워드클라우드는 해당 서비스의 새 탭에서 열립니다.

첨부된 우주 지도 이미지를 메인으로 사용하는 초등 데이터 학습 통합 사이트입니다.

- 1차시: 데이터 분류하기 → 데이터 테트리스
- 2차시: 숨은 데이터 찾기
- 3차시: 데이터 시각화 밸런스게임
- 4차시: 교과서를 활용한 데이터 문제 해결 안내 → 초등이지통계 / 워드클라우드 새 탭 링크
- 5차시: 데이터런

메인 이미지의 각 행성 또는 하단 차시 메뉴를 선택하세요. 차시 내부의 활동 메뉴와 하단 이전·다음 버튼으로 이동할 수 있습니다. 전체 화면 버튼으로 활동만 크게 볼 수 있습니다. 전체 화면 닫기 또는 Esc로 돌아옵니다. 활동 이동 시 진행 중 게임은 다시 시작하므로 활동을 마친 뒤 이동하세요. 원본에서 브라우저 저장을 지원하는 입력은 해당 기능을 그대로 사용합니다.

## 실행 및 배포

빌드 과정이나 API 키가 필요 없는 정적 사이트입니다. GitHub Pages 설정에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다. 모든 내부 자산은 상대 경로로 연결되어 프로젝트 경로에서도 동작합니다.
