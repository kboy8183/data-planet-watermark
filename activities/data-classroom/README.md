# 데이터 분류하기

초등학생을 위한 데이터 분류 학습 웹앱입니다.

1. 데이터 카드 8개를 두 묶음으로 나눕니다.
2. 분류 기준과 두 묶음의 이름을 적습니다.
3. 결과를 확인하고 PNG 이미지로 저장합니다.

마우스 드래그 또는 카드 선택 후 분류함 클릭으로 카드를 옮길 수 있습니다. 분류함에 키보드로 초점을 맞추고 Enter 또는 Space를 눌러도 선택한 카드를 옮길 수 있습니다. 작성 내용은 사용하는 브라우저에 저장됩니다.

## 실행

별도 설치나 빌드 없이 정적 웹 호스팅에서 `index.html`을 제공합니다. 도현체와 제공된 로봇 이미지가 파일에 포함되어 있습니다.

## GitHub Pages

저장소의 Settings → Pages에서 Deploy from a branch를 선택하고 `main` 브랜치의 `/ (root)`를 배포 소스로 지정합니다.
