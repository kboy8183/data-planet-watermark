# 데이터 테트리스

초등학생이 수치형 데이터와 범주형 데이터를 구분하며 즐기는 웹 게임입니다.

## 게임 진행

1. 캐릭터의 게임 방법과 데이터 유형 안내를 확인합니다.
2. 가운데 문제를 보고 수치형 또는 범주형을 선택합니다.
3. 정답과 해설을 확인한 후 정답인 게임판에서 블록을 놓습니다.
4. 가로줄을 채우면 줄이 사라집니다. 오답이면 정답 판 아래에 벌칙 한 줄이 추가됩니다.

PC에서는 방향키와 스페이스 키를, 모바일과 태블릿에서는 화면의 조작 버튼을 사용합니다. 이동·내리기 버튼을 길게 누르면 연속 조작할 수 있습니다.

## 실행 및 배포

설치나 빌드 없이 `index.html`을 브라우저에서 열면 실행됩니다. GitHub Pages에서는 `main` 브랜치의 루트(`/`)를 배포 위치로 사용합니다.

`dohyeon.ttf`와 `robots.png`는 제작자가 제공한 폰트와 캐릭터 이미지입니다.
