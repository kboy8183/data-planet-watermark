# 데이터로 바라보는 세상

초등학교 5학년 둘째마당 2차시 **데이터 수집** 활동을 위한 정적 웹앱입니다.

## 활동
1. 학교 지도에서 급식실·도서관·교실·복도·화장실·운동장을 선택합니다.
2. 그림 속에서 데이터를 발견한 위치를 눌러 카드를 작성합니다.
3. ‘내가 발견한 데이터’의 카드를 누르면 수집하고 싶은 데이터에 바로 반영됩니다.
4. 학교 지도와 모든 발견 카드, 선정 내용을 PNG 이미지로 저장합니다.
5. 교과서 40~43쪽에 데이터 수집 계획을 세우고 꾸준히 기록합니다.

그림 크게 보기, 카드 수정·삭제, 브라우저 자동 저장을 지원합니다. 날짜·식단·온도 등 그림의 정보는 학습용 예시입니다.

## 실행 및 배포
- HTML, CSS, JavaScript만 사용하므로 설치나 빌드가 필요하지 않습니다.
- GitHub Pages: main 브랜치의 / (root)를 배포 원본으로 지정합니다.
- 다른 차시와 통합하려면 이 폴더를 별도 경로에 두고 링크 또는 iframe으로 연결하세요.
- 카드와 선정 내용은 사용하는 브라우저의 localStorage에만 저장되며 서버로 전송되지 않습니다.

## 파일
- index.html: 화면 구성
- style.css: 스타일 및 사용자 제공 도현체
- app.js: 지도·카드·선정·PNG 저장 동작
- assets/: 학교 지도, 장소별 이미지, 로봇 이미지, 글꼴

이미지와 글꼴은 수업 제작을 위해 제공된 자료입니다.
