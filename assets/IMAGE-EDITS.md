# 이미지 편집 기록

기본 제공 imagegen 도구로 사용자 제공 이미지를 편집했습니다.

- `main-grade5.png`: 기존 메인 이미지에서 제목은 ‘데이터 플래닛’으로 유지하고 부제만 ‘WITH 5학년 디지털 사회와 인공지능’으로 교체. 다른 행성, 위치, 문구와 색상 보존.
- `daegu-education.png`: 사용자 제공 대구광역시교육청 로고의 흰 배경을 투명하게 제거. 원래 심벌, 한글 이름, 색상과 가로 배치 보존.

기존 메인 이미지 `main.png`는 원본으로 보관합니다.

- `main-seamless.png`: 기본 제공 imagegen 편집 도구 사용. 최종 프롬프트: 기존 두 상단 행성의 원형 외곽을 그대로 유지하면서, 교육청의 원형 심벌만 행성 표면 무늬로 통합한다. 원래 행성의 빈 초승달 부분이나 별도 겹친 원이 남지 않도록 표면 전체를 채우고, 왼쪽 행성의 앞쪽 고리를 유지한다. 심벌의 한글 이름과 아래 타원 그림자는 제외한다. 제목·부제와 다섯 차시 메뉴의 위치·문구·구성은 유지한다.
